## What is react-splitkit?

**react-splitkit** is a headless layout library for React that lets you build IDE-grade,
resizable, tabbed panel layouts — without any imposed styling.

You supply the chrome (tab bars, resizers, panel wrappers). The library manages
all the state: sizes, active tabs, splits, collapse, and maximize.

```bash
npm install react-splitkit
```

## Features

- **Headless** — zero styles; you bring Tailwind, CSS-in-JS, or plain classnames
- **Resizable** — drag dividers to resize in any direction
- **Tabbed** — each panel holds multiple tabs; add, remove, and reorder at runtime
- **Splittable** — panels split horizontally or vertically programmatically
- **Collapsible / Maximizable** — built-in collapse and maximize out of the box
- **Composable** — nested splits compose recursively to any depth
- **TypeScript-first** — fully typed with exported types for all primitives

- **Found a bug?** [Open an issue](https://github.com/amareshsm/react-splitkit/issues/new?labels=bug) with a minimal reproduction and we'll take a look.
- **Have a feature request?** [Start a discussion](https://github.com/amareshsm/react-splitkit/issues/new?labels=enhancement) describing your use case — we consider all requests.
